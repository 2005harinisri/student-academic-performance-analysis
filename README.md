# Student Academic Performance Dashboard (demo prototype)
1. Open this folder in VS Code, then open a terminal.
2. (Optional) python -m venv .venv  &&  activate it.
3. pip install -r requirements.txt
4. streamlit run app.py
Put your logo at assets/karunya_logo.png (a text fallback is shown if missing).
